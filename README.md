# NOWAY Map Editor

## First setup

Clone this repository:

git clone <repository-url>

Do not download it as ZIP.

## Run

### Windows

Double-click:

windows/Launch.bat

### macOS

Double-click:

macos/Launch.command

## Update

### Windows

windows/Update.bat

### macOS

macos/Update.command

## Your files

All project work belongs in:

workspace/maps
workspace/tilesets
workspace/sprites
workspace/props

Do not store project files inside the application folder.

The workspace is not overwritten by editor updates.
